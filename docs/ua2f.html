UA2F Optional Guide

UA2F is an optional third-party dependency. No binary is bundled here.

Install

opkg update
opkg install ua2f

# APK-based releases
apk update
apk add ua2f

Enable

uci set ua2f.enabled.enabled=1
uci set ua2f.firewall.handle_fw=1
uci commit ua2f
/etc/init.d/ua2f enable
/etc/init.d/ua2f restart

Verify

/etc/init.d/ua2f status
ps w | grep '[u]a2f'

Disable

/etc/init.d/ua2f stop
/etc/init.d/ua2f disable
